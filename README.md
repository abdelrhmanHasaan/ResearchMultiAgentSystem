🚀 Research System Backend

A backend service for running the research system locally. This service powers data processing, analysis, and API endpoints.

⚙️ Setup & Installation

Follow these steps to get the project running on your machine:

1. Create a Virtual Environment
python -m venv venv
2. Activate the Virtual Environment
Windows
venv\Scripts\activate
Mac/Linux
source venv/bin/activate
3. Install Dependencies
pip install -r requirements.txt
▶️ Running the Server

Start the backend server with:

python main.py

Once running, you should see:

Server running on http://localhost:8679
📡 API Access

You can now connect your frontend or test endpoints using tools like Postman or curl.
